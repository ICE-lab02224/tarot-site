# ดวงดาวทาโรต์

เว็บดูดวงไพ่ทาโรต์ออนไลน์ เขียนด้วย PHP ล้วน ไม่ต้องใช้ฐานข้อมูล ใช้กับโฮสติ้งราคาถูกทั่วไปได้

- เปิดไพ่ฟรี 3 ใบที่หน้าแรก (เลือกหัวข้อ เลือกไพ่เอง เปิดดูความหมาย และสรุปผล)
- 6 แพ็คเกจ ลูกค้าสแกนจ่ายพร้อมเพย์ แล้วเลือกไพ่เองและได้คำทำนายอัตโนมัติทันที
- รับเงินได้ 3 แบบ: โหมดทดลอง / QR พร้อมเพย์ (ร้านกดยืนยัน) / Omise (อัตโนมัติ)
- หน้าหลังร้าน `admin.php` ดูคำสั่งซื้อและรายได้

วิธีลองเล่นและวิธีเอาขึ้นเว็บจริง อ่านที่ [คู่มือขึ้นเว็บ.txt](คู่มือขึ้นเว็บ.txt)

ตั้งค่าทุกอย่าง (ชื่อร้าน ราคา วิธีรับเงิน รหัสหลังร้าน) ที่ `includes/config.php`
