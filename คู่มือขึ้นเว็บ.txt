เว็บนี้เขียนด้วย PHP ธรรมดา ไม่ต้องใช้ฐานข้อมูล
แค่มี "โฮสติ้ง" (พื้นที่เก็บเว็บ) ที่รองรับ PHP ก็ใช้ได้ทันที

--------------------------------------------------
ขั้นที่ 0  (ไม่บังคับ) ลองเล่นเว็บในคอมตัวเองก่อน
--------------------------------------------------
1. ดาวน์โหลดและติดตั้งโปรแกรม XAMPP จาก apachefriends.org (ฟรี กด Next ไปเรื่อย ๆ)
2. เปิด XAMPP Control Panel แล้วกด Start ที่บรรทัด Apache
3. คัดลอกโฟลเดอร์ tarot-site ไปไว้ใน C:\xampp\htdocs\
4. เปิดเบราว์เซอร์ไปที่ http://localhost/tarot-site
   ตอนนี้เว็บอยู่ใน "โหมดทดลอง" กดจ่ายเงินแบบจำลองได้ ไม่มีเงินจริง
   หน้าหลังร้าน: http://localhost/tarot-site/admin.php  (รหัส change-me-1234)

--------------------------------------------------
ขั้นที่ 1  เช่าโฮสติ้ง + จดชื่อเว็บ (โดเมน)
--------------------------------------------------
- เลือกผู้ให้บริการเว็บโฮสติ้งแบบ "Shared Hosting" ที่รองรับ PHP 7.4 ขึ้นไป
  (ผู้ให้บริการไทยหลายเจ้ามีแพ็กเกจเริ่มต้นราคาไม่กี่ร้อยบาทต่อปี
   และมักแถมโดเมนหรือจดโดเมนให้พร้อมกัน)
- ตอนสมัคร ให้จดชื่อเว็บ เช่น duangdaotarot.com
- สิ่งที่ต้องเช็กก่อนซื้อ: รองรับ PHP, มี cPanel หรือ Plesk, มี SSL ฟรี (https)
- เมื่อสมัครเสร็จ ผู้ให้บริการจะส่งอีเมลที่มี "ลิงก์เข้าระบบจัดการ (cPanel)"
  พร้อมชื่อผู้ใช้และรหัสผ่านมาให้

--------------------------------------------------
ขั้นที่ 2  แก้ข้อมูลร้านของคุณ (ทำในคอมก่อนอัปโหลด)
--------------------------------------------------
- แตกไฟล์ tarot-site.zip ในเครื่อง
- เปิดไฟล์ includes/config.php ด้วยโปรแกรม Notepad (หรือ VS Code)
- แก้ข้อความในเครื่องหมาย ' ' ให้เป็นของคุณ (ห้ามลบเครื่องหมาย ' หรือ , ทิ้ง):
    name           = ชื่อร้าน
    line_id / line_url = ไลน์ของร้าน
    phone, promptpay, promptpay_name = เบอร์และบัญชีรับเงิน
    admin_password = รหัสสำหรับดูรายการจอง  <<< ต้องเปลี่ยน!
- ราคาและรายละเอียดแพ็คเกจอยู่ในไฟล์เดียวกัน ตรงส่วน $PACKAGES แก้ตัวเลขได้เลย
- รีวิวลูกค้าอยู่ในส่วน $REVIEWS ตอนนี้ว่างไว้ ส่วนรีวิวจึงไม่แสดงบนเว็บ
  เมื่อมีลูกค้าจริงรีวิวมาแล้วค่อยใส่ (อย่าแต่งรีวิวขึ้นเอง)
- บันทึกไฟล์ (ต้องเป็นแบบ UTF-8 ซึ่ง Notepad รุ่นใหม่ตั้งไว้ให้อยู่แล้ว)

--------------------------------------------------
ขั้นที่ 3  อัปโหลดเว็บขึ้นโฮสติ้ง
--------------------------------------------------
1. เข้า cPanel ตามลิงก์ในอีเมล
2. กดเมนู "File Manager" (ตัวจัดการไฟล์)
3. เข้าไปในโฟลเดอร์ชื่อ public_html  (บางเจ้าชื่อ httpdocs หรือ www)
4. ลบไฟล์ index.html เดิมของโฮสติ้งทิ้ง (ถ้ามี)
5. กด "Upload" แล้วเลือกไฟล์ tarot-site.zip (ฉบับที่แก้ config แล้ว ให้ zip ใหม่)
6. กลับมาที่ File Manager คลิกขวาที่ไฟล์ zip แล้วกด "Extract" (แตกไฟล์)
7. ถ้าแตกแล้วได้โฟลเดอร์ tarot-site ให้เข้าไปข้างใน เลือกทุกไฟล์
   แล้วกด "Move" ย้ายออกมาไว้ที่ public_html โดยตรง
   (ต้องเห็น index.php อยู่ใน public_html ทันที)
8. ลบไฟล์ zip ทิ้งได้

--------------------------------------------------
ขั้นที่ 4  เปิด https (ให้มีรูปกุญแจ)
--------------------------------------------------
- ใน cPanel หาเมนู "SSL/TLS Status" หรือ "Let's Encrypt" แล้วกดเปิดใช้กับโดเมนของคุณ
- ส่วนใหญ่ฟรีและทำงานอัตโนมัติ

--------------------------------------------------
ขั้นที่ 5  ทดสอบ
--------------------------------------------------
1. เปิดเว็บ https://ชื่อเว็บของคุณ  ลองกดเลือกหัวข้อ เลือกไพ่ 3 ใบ แล้วเปิดดู
2. ลองกด "เลือกแพ็คเกจนี้" กรอกข้อมูลทดสอบ จ่ายเงินแบบจำลอง แล้วเลือกไพ่
3. เปิด https://ชื่อเว็บของคุณ/admin.php  ใส่รหัสที่ตั้งไว้
   ต้องเห็นคำสั่งซื้อที่เพิ่งทดสอบ

ถ้าสั่งแล้วขึ้น "บันทึกข้อมูลไม่สำเร็จ":
  ใน File Manager คลิกขวาโฟลเดอร์ data > "Change Permissions" ตั้งเป็น 755
  (ถ้ายังไม่ได้ ลอง 775)

--------------------------------------------------
ขั้นที่ 6  เลือกวิธีรับเงิน (ก่อนเปิดขายจริง ต้องเปลี่ยนจากโหมดทดลอง!)
--------------------------------------------------
เปิด includes/config.php หาบรรทัด  'mode' => 'demo'  แล้วเปลี่ยนเป็นแบบใดแบบหนึ่ง

 แบบ A  'promptpay'  (ฟรี ไม่มีค่าธรรมเนียม)
   - เว็บสร้าง QR พร้อมเพย์ที่ใส่ยอดเงินให้ลูกค้าสแกนเอง
   - ต้องใส่เบอร์พร้อมเพย์ของคุณในช่อง promptpay ให้ถูก
   - เมื่อเงินเข้า คุณกด "ยืนยันรับเงิน" ใน admin.php ครั้งเดียว
     หน้าของลูกค้าจะเปลี่ยนไปให้เลือกไพ่เองทันที (ไม่ต้องรีเฟรช)

 แบบ B  'omise'  (อัตโนมัติ 100% ไม่ต้องกดอะไรเลย)
   - สมัครร้านค้าที่ omise.co (ต้องยืนยันตัวตน/ร้านค้า มีค่าธรรมเนียมต่อรายการ)
   - นำ Public key และ Secret key จากหน้า Dashboard มาใส่ในช่อง
     omise_public_key และ omise_secret_key
   - ลูกค้าสแกน QR จ่ายเสร็จ ระบบเห็นเงินเข้าเองแล้วเปิดให้เลือกไพ่ทันที
   - แนะนำให้ลองด้วย "test key" ของ Omise ก่อน แล้วค่อยเปลี่ยนเป็น live key

--------------------------------------------------
การทำงานของระบบ (อัตโนมัติ)
--------------------------------------------------
- ลูกค้าเลือกแพ็คเกจ กรอกคำถาม > สแกนจ่าย > เลือกไพ่เองด้วยมือ
  > ระบบสร้างคำทำนายละเอียดทุกใบ พร้อมบทสรุปและของมงคล ทันที
- ลูกค้าได้ลิงก์ส่วนตัวไว้กลับมาอ่านคำทำนายได้ตลอด
- ทุกแพ็คเกจทำงานเองทั้งหมด ไม่ต้องมีหมอดู
  (ถ้าวันหนึ่งมีหมอดูจริง ค่อยเพิ่มแพ็คเกจคุยสดใน config.php โดยใส่ 'auto' => false)
- admin.php ดูคำสั่งซื้อทั้งหมด สถานะ และรายได้รวม
- อยากให้มีอีเมลแจ้งทุกครั้งที่มีคำสั่งซื้อ: ใส่อีเมลในช่อง email ของ config.php
  (บางโฮสติ้งอาจส่งอีเมลไม่ได้ ถ้าไม่ได้รับก็เช็กที่ admin.php แทน)
- ข้อมูลคำสั่งซื้อเก็บในโฟลเดอร์ data/orders ซึ่งคนนอกเปิดอ่านไม่ได้
  ควรดาวน์โหลดโฟลเดอร์ data เก็บไว้เป็นระยะเพื่อสำรอง
- อยากแก้คำทำนาย: ความหมายไพ่อยู่ใน includes/cards.php
  ประโยคตามตำแหน่งไพ่อยู่ใน includes/reading.php

--------------------------------------------------
โครงสร้างไฟล์ (เผื่ออยากรู้)
--------------------------------------------------
index.php             หน้าแรก + ลูกเล่นเปิดไพ่ฟรี + แพ็คเกจ
booking.php           หน้ากรอกข้อมูลสั่งดูดวง
order.php             หน้าจ่ายเงิน > เลือกไพ่ > อ่านคำทำนาย
admin.php             หลังร้าน ดูคำสั่งซื้อ/ยืนยันรับเงิน (ต้องใส่รหัส)
includes/config.php   ข้อมูลร้าน ราคา แพ็คเกจ วิธีรับเงิน  <<< ไฟล์หลักที่ต้องแก้
includes/cards.php    ความหมายไพ่ 22 ใบ
includes/reading.php  ระบบสร้างคำทำนายอัตโนมัติ
includes/functions.php ระบบเก็บคำสั่งซื้อ QR พร้อมเพย์ และ Omise
assets/               หน้าตาเว็บและลูกเล่น
data/orders/          ที่เก็บคำสั่งซื้อ
